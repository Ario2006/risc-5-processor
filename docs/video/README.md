# Recording the Phase I video

Each of us records **our whole segment as one take**, voice only, no camera. Navodit
records two takes, the opening and the closing.
Husain edits the takes together and shows the matching slide, code or terminal frame
full screen under each line. Final length is about 4:35.

## How to record

1. **Mic:** QuickTime Player, File, New Audio Recording works. A screen or phone recording
   is fine too; only the audio is used. Keep the mic at the same distance throughout.
2. **Room:** quiet, with the fan and AC off.
3. **One take for your segment.** Say your lines in order without stopping the recording.
4. **Pause briefly between lines.** About 2 seconds. That is where the edit switches the frame, and the pause gets trimmed.
5. **Stumbled?** Pause, then say the whole line again from the start. Keep recording. The edit keeps the last clean attempt.
6. **Say the line as written.** The numbers are checked against `results/`. Do not round them or add new ones.
7. **Tone:** like explaining it to a friend. Steady pace, and end each line as if it is the end of a sentence.

## Sending

Name the file as in the table above, in any audio or video format, and upload the
original to your folder in the shared Drive folder `Phase1 Video`. Do not send it over
WhatsApp, which compresses it. Say "uploaded" in the group.
